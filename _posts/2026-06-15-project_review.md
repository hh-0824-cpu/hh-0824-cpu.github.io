---

이번학기 인문데이터과학개론 수업에서는 GitHub Pages와 Jekyll을 이용해 개인 웹사이트를 구축하였다. 사이트에는 자기소개와 프로젝트 소개 페이지를 포함했으며, 두 편의 소설을 비교하는 단어 빈도 분석 페이지(compare), 고딕 소설인 *Frankenstein*과 *Dracula*를 비교하는 페이지(gothic), 그리고 사용자가 직접 영어 텍스트를 입력해 단어 빈도를 시각화할 수 있는 분석기(analyzer)를 구현하였다. 강의에서 배운 JavaScript, Fetch API, Chart.js를 활용하여 데이터를 불러오고 시각화하는 기능을 직접 구현해 볼 수 있었다.

프로젝트를 진행하면서 가장 어려웠던 부분은 여러 페이지와 스크립트를 통합하는 과정이었다. 특히 공통 함수들을 analysis.js로 분리한 뒤 compare.js와 gothic.js에서 재사용하도록 수정하는 과정에서 script 로드 순서 문제로 오류가 발생했다. 또한 fetch 경로를 잘못 지정하여 404 오류가 발생하기도 했고, analyzer 페이지에서는 차트를 여러 번 그릴 때 "Canvas is already in use" 오류가 발생했다. 맥북에서 더 문제가 발생하는 것 같기도 했다. 이러한 문제들은 스크립트 로드 순서를 수정하고, 기존 차트를 destroy()로 제거한 뒤 다시 생성하도록 변경하여 해결할 수 있었다.

텍스트 분석 결과 중 가장 흥미로웠던 점은 *Frankenstein*과 *Dracula*가 서로 다른 방식으로 이야기를 전개한다는 점이었다. *Frankenstein*에서는 life, mind, father와*같은*단어가 자주 등장하여 인간과 생명 창조의 문제를 중심으로 서사가 전개된다는 점을 확인할 수 있었다. 반면 *Dracula*에서는 Mina, Lucy, Helsing과*같은*인물 이름이 두드러져 여러 인물의 기록과 협력을 통해 이야기가 진행된다는 특징이 나타났다. 불용어를 제거한 뒤 단순한 단어 빈도 분석만으로도 작품의 주제와 서사 구조에 대한 흥미로운 차이를 발견할 수 있다는 점이 인상적이었고 계속 단어빈도를 검색하는 과정이 재밌었다.
